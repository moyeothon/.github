## ✏️ 심사 안내
### 심사 조건
|모여톤 트랙|플렉스튜디오 트랙|
|-|-|
|서비스의 설치 파일(.app) 링크, 혹은 웹 링크 제공|**플렉스튜디오를 사용해 만든** 서비스의 설치 파일(.app) 링크 제공|

### 심사 기준
**모여톤, 플렉스튜디오 트랙 모두 아래의 동일한 심사기준으로 심사를 진행합니다.**
1. 주제 적합도 (20)
    1. 주제를 얼마나 참신하게 가져왔는가?(주제 참신도)
    2. open ai API 등을 이용하여 인공지능을 서비스에 기획적으로 적합하게 결합하였는가
2. 기술적 완성도 (30)
    1. 제한된 시간 내에 얼마나 완성도 있게 서비스를 개발하였는가?
        1. 초기 서비스 진입부터 서비스 종료까지의 유저 경험 플로우에서의 완성도
    2. AI 도구를 얼마나 효과적으로 활용하여 기술적 완성도를 높였는가?
3. 혁신성 (30)
    1. 새로운 문제를 해결하고자 했는가? or 기존에 있던 문제라면, 차별점을 가지는가?
    2. 아이디어와 구현 방식이 얼마나 창의적인가?
4. 전달력 (20)
    1. 발표, PPT 등을 통하여 서비스를 얼마나 충분히 전달하였는가?
        1. 제한된 시간 내에 프로젝트를 효과적으로 설명하였는가?
        2. 데모/프로토타입이 잘 준비되었는가?
        3. Q&A 세션에서의 응답은 적절했는가?
